# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately. Use **Report a vulnerability** on
the repository's [Security Advisories page](https://github.com/patryk-zz/docz/security/advisories)
if that option is available.

If private reporting is unavailable, [open an issue](https://github.com/patryk-zz/docz/issues/new)
asking for a private contact method. Do not include vulnerability details,
exploit code, or sensitive data in that public issue.

In your private report, include:

- The affected version or commit.
- Your operating system and terminal, where relevant.
- Steps to reproduce using harmless sample files.
- The expected behavior, actual behavior, and security impact.

When possible, verify the issue against the latest commit on `main`.
Coordinate disclosure with the maintainer so a fix can be prepared.
